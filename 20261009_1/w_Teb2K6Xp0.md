## 一句話總結
OpenAI ChatGPT／Codex 負責人 Tibo Sottiaux 的兩個長訪談整理：模型會持續變強，別為今天的缺點寫拐杖。

## 背景
Tibo 比利時人，應用數學出身，曾任職 Google／DeepMind，2024 加入 OpenAI，先做推理模型與研究基礎設施，後帶 Codex；2026 五月接手 ChatGPT、Codex、API 核心產品部門。

## 核心論點（AI coding）
- harness（模型外殼）永遠走在模型前面一步，像拐杖；模型變強後外殼會越來越薄。
- 原則：若為了繞過模型缺點寫一大堆程式碼，大概是做錯了。先問「改 harness 還是等模型」。
- 決定 agent 與產品介面分開（核心用 Rust）；邊界清楚才改得快。
- code review：AI 抓錯能力在測試中已超過人；PR 一律先過 AI 資安審查，人才討論「想做什么、值不值得做」。

## Codex 與 Dots
- Dots 是全天候個人 agent，harness 不跑在你電腦上，有自己的電腦（像章魚可控制多台裝置）。
- 第一版雲端 Codex 摩擦太高、沒找到市場；Dots 是兩年長任務研究＋記憶系統＋Codex harness 累積而成。
- 別把 agent 流程圖寫死：模型一升級，一個更強 agent 就全做完，分工可能整個用不到。

## AI 時代最重要的能力
- 掉價：打字快。升值：好品味、想著使用者、跟你服務的人群保持連結。
- 好奇心（連問五個為什麼）、想清楚並講清楚意圖。
- 不會再有「寫程式的人」這角色，但動手把東西做出來的人會更多。

## 未來三件事
- 網路大部分動作將由 agent 執行。模型變便宜、變快的速度驚人。語音與圖像輸入輸出終能順暢整合。

## 六句行動指南
1. 動手前先問：這問題模型是不是很快自己就會。
2. 讓 AI 檢查正確性與資安，人討論「想做什麼」。
3. 別把 agent 分工寫死，模型升級就重來。
4. 把工作放在 agent 讀得到的地方（公開頻道、開放文件）。
5. 練品味與講清楚意圖；打字快不再重要。
6. 做任何事前，先想像一年後一切都好上 10 倍。
