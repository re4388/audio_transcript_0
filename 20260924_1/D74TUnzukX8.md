# 【咬指甲、剝手皮】可能是什麼生理/心理問題？

## 一句話總結
咬指甲、剝手皮不只是壞習慣，多半是「生理（神經傳導物質／營養素）＋心理（壓力創傷）／純習慣」三類成因之一，對症處理才有效。

## 核心論點
1. **神經傳導物質失衡**是主因之一：
   - **多巴胺偏低**（注意力不足／過動 ADHA 族群常見）：透過咬、剝等外來刺激讓自己平靜、專心。
   - **血清素（寫輕素）偏低**：造成焦慮、衝動、易怒、執著、完美主義與重複行為，類似強迫行為；兩類皆可經醫師評估以藥物調整。
2. **營養素不均衡**：
   - **缺鋅**：指甲破損、出現白色斑痕、胃口差、個子小、傷口難癒合；可抽血檢驗，未達紅字但偏低即可補。來源：帶殼海鮮、紅肉（牛羊）、肝臟（豬肝湯）。
   - **生物素**（B 群）：缺乏則皮膚、指甲長不好。
   - **維他命 C**：與膠原蛋白生成、皮膚指甲狀況相關。
   - **蛋白質不足**：愛吃澱粉零食、糖與精緻碳水過多，身體易發炎，傷口難好。
3. **心理因素**：緊張、焦慮、內在壓力與創傷（含隱藏式壓力、情緒壓抑）。
4. **單純習慣**：心情 OK 但習慣性咬（如多數人小時候咬筆頭咬爛）。此類只需「轉移」——如改為按摩指節、轉筆。

## 關鍵洞察
- 咬到流血還停不下來，往往是因為那一點痛能讓神經傳導物質「拉上來」，讓人平靜、舒服、專心；不做反而痛苦。
- 兒童若有情緒因素，建議尋求兒童心理師專業評估（政府亦有相關方案）；若只是習慣，則用轉移法即可。
- **家長切勿因此責怪孩子**，否則會加重焦慮、將問題壓抑或引爆，得不償失。

## 因應對策總整理
| 成因 | 對應處理 |
|------|----------|
| 多巴胺／血清素偏低 | 經醫師評估，藥物調整 |
| 缺鋅、生物素、維他命 C、蛋白質 | 檢驗後補充、均衡飲食 |
| 心理壓力／創傷 | 兒童心理師專業協助 |
| 單純習慣 | 轉移（按摩指節、轉筆等） |
