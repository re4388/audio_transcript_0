# 我實測 Claude + Jev，竟然能玩出這 3 種應用

- **頻道**：JayLuxAI
- **影片 ID**：EbJzxrhaXmM
- **時長**：9:41
- **逐字稿方式**：mlx-whisper（small，Metal GPU）

## 一句話總結
Jev 是 ChatGPT 共同發明人推出的新模型，只做判斷、不生成內容，速度比 Claude 快上百倍、成本只有幾百分之一。把它接到 Claude 工作流裡當「判斷層」，Claude 負責執行，就能玩出挑模型、挑技能、即時分流三種應用。

## 核心論點
1. **Jev 只做兩件事：快、便宜**：官方說法是一般模型快 20 到 200 倍、便宜 40 到 400 倍，輸出部分完全免費。給它 100 萬個 token，只要約 4 分錢美金。
2. **三種輸出形式**：第一種是二選一（判斷對或不對）；第二種是多選（從幾個選項裡挑一個）；第三種是評分（0 到 10 分裡挑一個最有可能的數字）。這三種形式就是它又快又便宜的原因。
3. **Jev 只說判斷，不說事情**：它不會幫你寫文章，只會告訴你是或不是、選哪個、得幾分。Claude 才是真正執行任務、產出內容的那個，所以這支影片的重點不是拿 Jev 取代 Claude，而是讓兩者接在一起：Jev 當快速的判斷節點，Claude 做後續處理與產出。
4. **用法一、二：讓 Jev 挑模型、挑 skill**：拿 12 個任務去比較，大部分任務根本不需要用到最貴的模型，光是先讓 Jev 判斷路由就能省下很多成本；工作區裡有一百多個 skill 時全部塞進 context 也很浪費，先讓 Jev 判斷該用哪一個可以省很多錢。
5. **怎麼取得與接入**：到 TypeSafe 官網或透過 OpenRouter 拿 API key（作者覺得 OpenRouter 操作比較簡單），拿到之後就像其他模型一樣，直接把 model 名稱貼給 Claude，跟它說你要串接 Jev，它就能幫你設定好。
6. **只需要給它兩樣東西**：一是資料（一句話、一封信或一張圖片的描述），二是你要的 type（二選一、多選或分數）。Jev 就會依這個 type 回傳判斷結果。確認垃圾信就用二選一，客服單分類就用多選，潛在客戶意願就從 0 到 10 評分。
7. **實測一：名單篩選**：拿 50 筆真實社團會員問卷請 Jev 分類，跟 Claude Sonnet 5 對照。Jev 花 1.7 秒、成本 0.0017 美金；Sonnet 花 13.0 秒、成本 0.07 美金。要處理多筆資料時，Jev 是最佳選擇。
8. **實測二：模擬比特幣交易員**：即時接 Coinbase 的比特幣價格，每五秒問 Jev 一次接下來會漲、會跌還是不確定，再依信心程度在 1000 美元的模擬帳戶自動買進賣出。作者強調這是模擬練習、不是投資建議；重點在於每幾秒跑一次如果用其他模型，等待時間與成本會高很多。
9. **實測三：潛在客戶即時分流**：每進來一筆新諮詢，Jev 立刻判斷是 hot、warm 還是 cold。hot 代表對方有明確預算和時程、畫面立刻提醒；warm 交給自動回覆；cold 直接略過。
10. **心法總結**：Jev 對處理多筆資料、做即時判斷這類任務非常擅長。把 Jev 跟 Claude 對接之後，流程就變成 Jev 做快速判斷、Claude 做後續處理，整體效率提升到另一個層次。

## 關鍵洞察
- 判斷與生成是兩種不同的工作，把它們拆開交給不同模型，是這支影片最核心的省錢邏輯。
- 任務路由（挑模型、挑 skill）是最高投報率的切入點，因為它不需要改變你原本的使用習慣。
- 成本差距在「高頻、多筆、即時」的場景會被放大：每五秒跑一次、50 筆一次跑完，換模型就差好幾十倍。
- 判斷型任務的關鍵是選對 type——二選一、多選或評分，選對了 Jev 就會又快又準。
- Jev 的定位是工作流裡的「決策節點」，它不產出內容，而是決定接下來該由誰、用什麼方式處理。
